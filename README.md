# MBA em Desenvolvimento Full Stack - Unyleya

Este repositório centraliza todas as atividades, projetos e estudos realizados durante o curso de **Pós-Graduação MBA em Desenvolvimento Full Stack** da
Faculdade Unyleya.

## 🚀 Sobre o Curso

O curso abrange as principais tecnologias e metodologias do mercado atual, focando na formação de um desenvolvedor full-stack, abordando desde o front-end até o
back-end e infraestrutura como AWS Cloud e AWS Devops.

## 📁 Estrutura do Repositório

O repositório está organizado por disciplinas conforme o andamento do curso:

- `/backend`: Atividades relacionadas a materia de Back-End Development.
- `/frontend`: Atividades relacionadas a materia de Front-End Development .
- `/aws-cloud`: Atividades relacionadas a materia de AWS Cloud.
- `/aws-devops`: Atividades relacionadas a materia de AWS Devops.
- `/modern-web`: Atividades relacionadas a materia de Modern Web.
- `/atividades-extras`: Documentações, exercícios teóricos e arquivos auxiliares das unidades.
